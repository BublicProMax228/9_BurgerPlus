# 9_BurgerPlus
Предметная область - магазин продажи бургеров
Разработанное приложение необходимо для автоматизации и категоризации информации для удобства работников бургерной.
Функционал для администратора: вход в систему с помощью пароля и логина, удаление, изменение, добавление новых пользователей
Функционал для пользователя: вход в систему с помощью пароля и логина
реализована капча и блокировка пользователя через 3 неверные попытки входа через логин пользователя, или неправильный ввод капчи.
для реализации использовалась Visual Studio, xml, c#
требования к ПО: 
•	Монитор 800х500 точек
•	Клавиатура
•	Мышь
•	Видеоадаптер gt600 и выше
•	Процессор i3 3600 и выше
•	Оперативная память 1 ГБ
•	Дисковое пространство 20 ГБ
•	Операционная система Windows 7 и выше
Для установки необходимо скачать с репозитория проект, пройти по пути
